# Hero images pour les group details

## Comment ajouter des images manuellement

1. **Créer le dossier** : `{groupCode}/group-details/`  
   Exemple : `215/group-details/`, `417/group-details/`

2. **Mettre toutes vos photos** dedans  
   Noms libres : `photo.jpg`, `1.png`, `image.webp`, etc.  
   Extensions : .jpg, .jpeg, .png, .webp, .gif  
   Aucune limite – toutes les images s’affichent et sont scrollables.

3. **C’est tout.**  
   Les images apparaissent dès que vous les mettez dans le dossier.

**Fallback** : si `group-details/` n’existe pas, on utilise `{groupCode}/` directement (group-details-1.jpg, etc.).
